# PolicyEngine September 2025 event

Planning hub for PolicyEngine's September 2025 event.

## View the site

Open `index.html` in your browser to view the planning hub.

## Deployment

This site is designed to be hosted on GitHub Pages. Push to the main branch and the site will be automatically deployed.

## Structure

The site is a single HTML page with tabbed navigation containing:
- Event overview and timeline
- Event planning details
- Task tracker
- Logistics information
- Venue recommendations
- Contact information

One Great George Street - Brunel Room on Friday 26th September 2025 for 35 attendees.
