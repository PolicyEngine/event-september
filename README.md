# PolicyEngine September 2025 event

Planning hub for PolicyEngine's September 2025 event.

## Live site

Visit the live planning hub at: https://policyengine.github.io/event-september/

## Local development

Open `index.html` in your browser to view the planning hub locally.

## Deployment

This site is automatically deployed to GitHub Pages when changes are pushed to the main branch.

### Setup GitHub Pages (if not already configured)

1. Go to repository Settings → Pages
2. Set Source to "Deploy from a branch"
3. Select "main" branch and "/ (root)" folder
4. Click Save

The site will be available at `https://policyengine.github.io/event-september/` within a few minutes.

## Structure

The site is a single HTML page with tabbed navigation containing:
- Event overview and timeline
- Event planning details
- Task tracker
- Logistics information
- Venue recommendations
- Contact information
